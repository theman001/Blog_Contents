## 개요

이 글은 **Blog Project** 시리즈의 네 번째 글로,  
이 블로그가 **어떻게 배포되고 운영되는지**, 그리고 왜 **Cloudflare Pages**를 선택했는지를 정리한다.

이 프로젝트의 배포 전략은 한 문장으로 요약할 수 있다.

> **“빌드 없이, 서버 없이, 가능한 한 단순하게.”**

블로그라는 서비스의 성격상  
복잡한 인프라보다는 **안정적이고 관리 부담이 적은 구조**가 더 중요했다.

> 🔗 GitHub Repository  
> [레포지토리 바로가기](https://github.com/theman001/IT-Security_Blog)

## 배포 전략의 전제 조건

배포 구조를 설계할 때, 다음 전제를 먼저 정리했다.

- 이 블로그는 **정적 웹**이다
- 서버 사이드 렌더링이 필수적이지 않다
- 실시간 처리나 세션 관리가 필요 없다
- 트래픽은 많지 않지만, 언제든 안정적으로 접근 가능해야 한다

즉,  
**“운영을 거의 의식하지 않아도 되는 구조”**가 목표였다.

---

## Cloudflare Pages를 선택한 이유

정적 웹 호스팅을 위한 선택지는 많다.  
(GitHub Pages, Netlify, Vercel 등)

그중에서 Cloudflare Pages를 선택한 이유는 다음과 같다.

### 1. 빌드 없는 정적 배포

이 프로젝트는:

- npm
- bundler
- transpiler

어떤 것도 필요 없다.

HTML / CSS / JS 파일 그대로를  
**문서 루트로 지정해 배포**하면 끝이다.

Cloudflare Pages는 이런 구조를 가장 자연스럽게 지원한다.

---

### 2. 글로벌 CDN 기본 제공

Cloudflare Pages는 배포 즉시  
**Cloudflare의 글로벌 엣지 네트워크**에 콘텐츠를 올려준다.

- 별도 CDN 설정 불필요
- HTTPS 자동 적용
- 캐시 전략 고민 최소화

블로그 규모에서는  
“설정하지 않아도 기본이 충분히 좋다”는 점이 가장 큰 장점이다.

---

### 3. Git 기반 자동 배포

배포 흐름은 매우 단순하다.

1. GitHub 레포지토리에 코드 Push
2. Cloudflare Pages가 변경 감지
3. 자동으로 최신 버전 배포

이 과정에서,

- 배포 스크립트 ❌
- 서버 접근 ❌
- 수동 작업 ❌

**코드를 올리는 행위 자체가 배포**가 된다.

---

## 실제 배포 구조

이 프로젝트의 배포 구조는 다음과 같다.

- **Repository**: IT-Security_Blog (Frontend)
- **Branch**: `main`
- **Root Directory**: `/public`
- **Build Command**: 없음

Cloudflare Pages 설정에서  
`/public` 디렉토리를 문서 루트로 지정하는 것만으로 배포가 완료된다.

---

## SPA 구조와 정적 호스팅의 궁합

이 블로그는 SPA 구조이기 때문에,  
정적 호스팅 환경에서 한 가지 고려가 필요하다.

### 모든 경로는 index.html로 귀결되어야 한다

예를 들어,

- `/`
- `/posts/xxx`
- `/hidden`

모든 요청은 결국 `index.html`을 반환해야 한다.

Cloudflare Pages는  
**SPA를 위한 리다이렉트 설정을 기본적으로 지원**하기 때문에,  
별도의 서버 설정 없이 이 요구사항을 충족할 수 있다.

---

## 운영 관점에서의 장점

Cloudflare Pages 기반 구조의 가장 큰 장점은  
**“운영할 것이 거의 없다”**는 점이다.

- 서버 패치 ❌
- 로그 관리 ❌
- 트래픽 대응 ❌
- 보안 설정 ❌

블로그 운영의 초점이  
인프라가 아니라 **콘텐츠와 구조 개선**에 맞춰진다.

---

## 한계와 고려 사항

물론 이 구조에도 한계는 있다.

- 서버 사이드 렌더링 불가
- 동적 API 처리는 별도 구성 필요
- SEO는 구조적 대응 필요

하지만 이 프로젝트에서는,

- 콘텐츠는 CSR로 충분
- 데이터는 외부 DB/API로 분리
- SEO는 메타데이터와 구조 개선으로 대응

이라는 판단을 내렸다.

Cloudflare Pages 기반 정적 배포는
