## 개요
이 글은 **Windows PC를 Active Directory(AD) 도메인에 조인하는 가장 기본적인 방법**을 간단히 정리한 게시글입니다.  
사내 PC 신규 도입, 테스트 VM 구성, AD 환경 점검 시 자주 사용되는 절차입니다.

---

## AD 조인 전 사전 조건
- AD 도메인 컨트롤러 정상 동작 상태
- 도메인 사용자 계정(도메인 조인 권한 보유)
- 네트워크 통신 가능 (DNS 포함)

---

## 1️⃣ DNS 설정 확인
도메인 조인을 위해 **DNS는 반드시 AD 서버를 바라봐야 합니다.**

1. `ncpa.cpl` 실행
2. 사용 중인 네트워크 어댑터 → 속성
3. **IPv4 설정**
   - 기본 DNS 서버: **AD01 서버 IP**
   - 보조 DNS 서버: **AD02 서버 IP**

> ⚠️ 공용 DNS(8.8.8.8 등)가 설정되어 있으면 도메인 조인 실패 가능성이 높습니다.

---

## 2️⃣ 도메인 연결
1. `sysdm.cpl` 실행
2. **컴퓨터 이름** 탭 → `변경`
3. **소속 그룹**에서 `도메인` 선택
4. 도메인 이름 입력 후 확인
5. 도메인 계정 인증 진행
6. 재부팅

---

## 3️⃣ 조인 결과 확인
- 재부팅 후 로그인 화면에서 **도메인 계정 선택 가능 여부 확인**
- AD 서버에서 **컴퓨터 객체 생성 여부 확인**

---

## 간단 체크 포인트
- DNS 설정이 가장 중요
- 조인 실패 시 이벤트 로그(System / Netlogon) 확인
- 시간 동기화 오류(Kerberos) 여부 점검
