## 개요
AWS re:Invent 2025 re:Cap의 대미를 장식한 **AI & GenAI** 세션에서는 AWS의 최신 AI 포트폴리오와 전략이 공개되었습니다.  
이번 발표의 핵심은 단순한 코딩 보조를 넘어, 실제 **업무(Work)를 수행하는 ‘에이전트(Agent)’의 본격적인 등장**과  
**한국어 처리 능력이 대폭 강화된 차세대 모델**의 공개였습니다.

---

## 1. 차세대 파운데이션 모델: Amazon Nova 2

AWS는 성능과 비용 효율을 동시에 고려한 자체 파운데이션 모델 라인업 **Amazon Nova 2**를 공개했습니다.  
특히 국내 사용자에게 가장 의미 있는 변화는 **한국어 음성 처리의 완성도**입니다.

### Nova 2 Sonic: 한국어 음성 대화의 실질적 도약
기존 음성 AI가  
[음성 → 텍스트 → 추론 → 텍스트 → 음성]  
이라는 복잡한 파이프라인을 거쳤다면, **Nova 2 Sonic**은 이를 단순화한 **Speech-to-Speech** 모델입니다.

- **실시간 대화:**  
  지연 시간(Latency)이 크게 줄어들어 사람과 대화하듯 자연스러운 상호작용 가능
- **한국어 시연:**  
  “안녕, 나 한국어 가능하지?”라는 질문에 즉각적이고 자연스러운 한국어 음성 응답 시연
- **감정·톤 제어:**  
  목소리 스타일과 톤 조절이 가능해 게임 NPC, 인터랙티브 콘텐츠, 음성 서비스에 적합

👉 음성 AI가 *기능 시연 단계*를 넘어 **실사용 가능한 수준**에 도달했음을 보여줍니다.

---

### Nova 2 모델 라인업
- **Nova 2 Lite**
  - 빠른 응답 속도, 낮은 비용
  - 요약, 간단 질의응답, 챗봇에 적합
- **Nova 2 Pro**
  - 복잡한 추론, 코딩, 수학 문제 해결에 특화
- **Nova 2 Omni**
  - 텍스트·이미지·비디오를 아우르는 멀티모달 통합 모델

## 2. 개발 방식의 전환: Spec-driven Development (Kiro)

AI 코딩 도구의 패러다임은 이제  
**코드 자동 생성 → 사양(Spec) 기반 개발**로 이동하고 있습니다.  
이를 대표하는 기능이 **Amazon Q Developer**의 신규 에이전트 **Kiro**입니다.

### 모호한 요청을 명확한 설계로
개발자가 “이런 기능 만들어줘”라고 말하면,  
Kiro는 이를 다음과 같이 구조화합니다.

- 요구사항 명세(Spec)
- 기능 목록
- 아키텍처 설계 초안

#### 개발 흐름 변화
1. 개발자: 의도와 목표 전달  
2. Kiro: Spec 문서 및 구조 제안  
3. 개발자: Spec 검토·수정  
4. Kiro: 확정된 Spec 기반 코드 생성

👉 결과적으로 **의도와 구현 간의 오차를 최소화**하고,  
기획·개발·리뷰 간 협업 효율을 크게 향상시킵니다.

## 3. 자율형 에이전트: Frontier Agents

AWS는 특정 도메인에서 **사람의 개입 없이 판단·행동하는 자율형 에이전트**,  
즉 **Frontier Agents** 3종을 공개했습니다.

### ① Kiro Autonomous Agent (개발)
- 단순 코딩 보조가 아닌 *동료 개발자* 역할
- 야간·비근무 시간에 백그라운드에서:
  - 코드 리팩토링
  - 테스트 케이스 작성
  - API 문서 최신화
- 개발자의 생산성을 **병렬적으로 확장**

---

### ② AWS Security Agent (보안)
- 기획 단계부터 배포까지 전 구간 보안 관여
- 정적 스캔을 넘어:
  - 공격 시나리오 기반 **침투 테스트(Pentesting)**
  - 취약점 발생 원인과 수정 가이드 제시
- DevSecOps 구현의 핵심 구성 요소

---

### ③ AWS DevOps Agent (운영)
- 장애 발생 시:
  - 로그·메트릭 자동 분석
  - Root Cause 분석
- 인프라 토폴로지 시각화
- Slack 등 협업 도구와 연동해:
  - 장애 현황 공유
  - 완화(Mitigation) 가이드 실시간 전달

👉 운영 대응의 **속도와 정확도**를 동시에 개선합니다.

---

## 4. Amazon Bedrock: 에이전트 개발의 중심

이 모든 에이전트를 구축·운영하는 기반 플랫폼은 **Amazon Bedrock**입니다.

- **Bedrock Agents**
  - 에이전트 개발·테스트·배포·모니터링까지 전 주기 관리
- **Evaluation 기능**
  - 에이전트의 정확도·안전성·일관성 수치화
  - 서비스 신뢰도 확보에 필수 요소

## 결론
이번 re:Invent AI 세션의 메시지는 명확합니다.

> **“AI가 일을 빼앗는 것이 아니라,  
> 사람이 더 중요한 ‘무엇(What)’에 집중하게 만든다.”**

- 한국어 음성 AI의 실사용을 가능하게 한 **Nova 2 Sonic**
- 개발 프로세스를 재정의하는 **Kiro**
- 개발·보안·운영 전반을 자동화하는 **Frontier Agents**

이제 AI는 실험 대상이 아니라,  
**업무 프로세스에 내재화되어야 할 동료**입니다.  
스마일게이트의 게임 개발 및 플랫폼 운영 환경에서도  
AI 에이전트를 **도입이 아닌 전제 조건**으로 바라봐야 할 시점입니다.

---

## 각주
1. **Kiro (Amazon Q Developer):** 사용자의 의도를 기반으로 요구사항 명세(Spec)를 생성하고, 이를 토대로 코드와 개발 작업을 자율적으로 수행하는 AI 에이전트 기능.
2. **Amazon Bedrock:** 다양한 파운데이션 모델을 단일 API로 제공하며, 보안·프라이버시를 준수한 상태로 생성형 AI 애플리케이션과 에이전트를 구축할 수 있는 완전 관리형 서비스.
