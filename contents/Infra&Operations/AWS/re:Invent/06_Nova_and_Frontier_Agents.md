## 개요
AWS re:Invent 2025 re:Cap의 대미를 장식한 **AI & GenAI** 세션에서는 AWS의 최신 AI 포트폴리오와 전략이 공개되었습니다. 이번 발표의 핵심은 단순한 코딩 보조를 넘어, 실제 업무(Work)를 수행하는 **'에이전트(Agent)'** 기술의 진화와 **한국어 처리 능력**이 대폭 강화된 신규 모델의 등장이었습니다.

## 1. 차세대 파운데이션 모델: Amazon Nova 2

AWS는 성능과 비용 효율성을 모두 잡은 자체 모델 라인업인 **Amazon Nova 2**를 공개했습니다. 특히 국내 사용자들에게 가장 반가운 소식은 바로 **한국어 음성 지원**입니다.

### Nova 2 Sonic: 한국어 음성 대화의 혁신
기존의 음성 AI가 [음성→텍스트→추론→텍스트→음성]의 복잡한 과정을 거쳤다면, **Nova 2 Sonic**은 음성 입력을 직접 이해하고 음성으로 출력하는 **Speech-to-Speech** 모델입니다.
*   **실시간 대화:** 지연 시간(Latency)이 획기적으로 낮아져 사람과 대화하듯 자연스러운 실시간 소통이 가능합니다.
*   **한국어 시연:** 데모에서는 "안녕, 나 한국어 가능하지?"라는 질문에 즉각적으로 자연스러운 한국어 목소리로 대답하는 모습을 보여주었습니다.
*   **감정 표현:** 사용자의 요청에 따라 목소리의 톤과 스타일을 변경할 수 있어 게임 NPC나 인터랙티브 콘텐츠 제작에 유용합니다.

### Nova 2 라인업
*   **Nova 2 Lite:** 가볍고 빠른 응답 속도를 제공하며, 단순 질의응답이나 요약 업무에 최적화된 가성비 모델.
*   **Nova 2 Pro:** 복잡한 추론과 코딩, 수학적 문제 해결 능력이 강화된 고성능 모델.
*   **Nova 2 Omni:** 텍스트뿐만 아니라 이미지, 비디오 등 멀티모달 입출력을 자유자재로 처리하는 통합 모델.

## 2. 개발 방식의 전환: Spec-driven Development (Kiro)

AI 코딩 도구의 패러다임이 '코드 자동 완성'에서 **'사양(Spec) 기반 개발'**로 이동하고 있습니다. 이를 주도하는 도구가 바로 **Amazon Q Developer**의 새로운 기능인 **Kiro**^1입니다.

### 모호함에서 명확함으로
개발자가 "이런 기능 만들어줘"라고 모호하게 말하면, Kiro는 이를 구체적인 **요구사항 문서(Spec)**와 **아키텍처 다이어그램**으로 변환합니다.
*   **협업 방식:** 개발자는 AI가 작성한 Spec을 검토하고 수정하는 역할을 맡습니다. Spec이 확정되면 Kiro가 이를 바탕으로 코드를 생성합니다.
*   **이점:** 모호한 지시로 인해 발생하는 엉뚱한 코드 생성을 방지하고, 기획 의도에 정확히 부합하는 결과물을 얻을 수 있습니다.

## 3. 자율형 에이전트: Frontier Agents

특정 도메인에서 사람의 개입 없이 자율적으로 판단하고 행동하는 고지능 에이전트인 **Frontier Agents** 3종이 소개되었습니다.

### ① Kiro Autonomous Agent (개발)
*   단순한 코딩 비서를 넘어, '동료 개발자'처럼 행동합니다.
*   개발자가 퇴근한 사이 백그라운드에서 코드 리팩토링, 테스트 케이스 작성, API 문서 현행화 등의 작업을 병렬로 수행합니다.

### ② AWS Security Agent (보안)
*   기획 단계부터 배포까지 전 과정에서 보안 위협을 모니터링합니다.
*   단순한 취약점 스캔을 넘어, 실제 공격 패턴을 시뮬레이션하는 **침투 테스트(Pentesting)**를 수행하고 해결 방안을 제시합니다.

### ③ AWS DevOps Agent (운영)
*   장애 발생 시 로그와 메트릭을 분석하여 근본 원인(Root Cause)을 찾아냅니다.
*   리소스 간의 관계(Topology)를 시각화하여 문제를 추적하며, 슬랙(Slack) 등을 통해 장애 상황과 완화(Mitigation) 가이드를 실시간으로 전파합니다.

## 4. Amazon Bedrock: 에이전트 개발의 중심

이 모든 에이전트를 만들고 운영하는 기반 플랫폼인 **Amazon Bedrock**^2의 기능도 강화되었습니다.
*   **Bedrock Agents:** 에이전트의 개발, 테스트, 배포, 모니터링까지 전체 수명 주기(Life-cycle)를 관리하는 기능을 제공합니다.
*   **평가(Evaluation):** 에이전트가 얼마나 정확하고 안전하게 동작하는지 수치화하여 평가할 수 있는 기능을 제공하여, 서비스 신뢰도를 높입니다.

## 결론
이번 re:Invent의 AI 세션은 **"AI가 우리 일을 뺏는 것이 아니라, 우리가 더 가치 있는 일(What)에 집중하게 해준다"**는 메시지를 명확히 했습니다.
한국어를 자유롭게 구사하는 **Nova 2 Sonic**과 개발 프로세스를 통째로 혁신하는 **Kiro**는 스마일게이트의 게임 개발 및 플랫폼 운영 환경에 즉시 적용 가능한 강력한 도구입니다. 이제는 단순한 '검토'를 넘어, 실제 업무 프로세스에 AI 에이전트를 **'내재화'**하는 전략이 필요한 시점입니다.

**각주**
1.  **Kiro (Amazon Q Developer):** 사용자의 의도를 파악하여 요구사항 명세(Spec)를 작성하고, 이를 기반으로 코드를 생성하며 복잡한 개발 작업을 자율적으로 수행하는 AI 에이전트 기능.
2.  **Amazon Bedrock:** 주요 파운데이션 모델(FM)을 API로 제공하며, 보안과 프라이버시를 준수하면서 생성형 AI 애플리케이션을 쉽고 빠르게 구축할 수 있는 완전 관리형 서비스.
