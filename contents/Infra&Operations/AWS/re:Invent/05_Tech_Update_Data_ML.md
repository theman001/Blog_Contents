## 개요
AWS re:Invent 2025 re:Cap의 마지막 기술 세션은 **Data & ML** 분야의 혁신을 다루었습니다. 스토리지와 컴퓨팅의 분리, 데이터 거버넌스 강화, 그리고 생성형 AI를 활용한 분석 자동화가 핵심 주제였습니다. 특히 데이터 엔지니어와 데이터 과학자가 인프라 관리 부담 없이 데이터 자체에 집중할 수 있도록 돕는 통합 도구들이 대거 공개되었습니다.

## 1. 스토리지 및 데이터 관리의 진화 (Analytics & Storage)

### Amazon S3 Tables: 분석을 위한 전용 버킷
기존 S3는 객체 스토리지로서 유연하지만, 대규모 분석을 위한 테이블 관리에는 복잡함이 있었습니다. **Amazon S3 Tables**는 S3 버킷 내에서 **Apache Iceberg**^1 테이블 형식을 네이티브로 지원하여 이 문제를 해결합니다 [1].
*   **성능 및 관리:** 분석 워크로드에 최적화된 성능을 제공하며, Iceberg 테이블 관리를 자동화합니다 [2].
*   **Intelligent Tiering 지원:** S3 Tables에도 데이터 접근 패턴에 따라 스토리지 클래스를 자동으로 변경하는 인텔리전트 티어링이 적용되어, 자주 접근하지 않는 데이터의 저장 비용을 절감할 수 있습니다 [2].

### 자동 데이터 분류 (Automatic Data Classification)
데이터 카탈로그를 구축할 때 가장 큰 어려움 중 하나는 메타데이터 관리입니다. 새로운 자동 분류 기능은 **AI를 활용**하여 데이터의 내용을 분석합니다 [3].
*   **기능:** 민감 정보(PII)나 비즈니스 용어(Business Glossary)를 자동으로 식별하고 태깅합니다.
*   **효과:** 조직 전체에서 일관된 데이터 보안 정책을 적용하고 데이터 검색 효율을 높일 수 있습니다 [3].

## 2. 분석과 ML의 통합: Amazon DataZone Unified Studio

이번 데이터 세션의 하이라이트는 단연 **Amazon DataZone Unified Studio**였습니다. 기존에는 데이터 수집, 정제, 분석, 시각화, ML 모델링을 위해 각각 다른 도구를 오가야 했지만, 이제는 하나의 통합된 스튜디오에서 모든 작업이 가능해집니다 [1, 4].

### 주요 특징
*   **통합 환경:** 데이터 엔지니어, 분석가, ML 엔지니어가 동일한 프로젝트 공간에서 협업할 수 있습니다. Amazon Athena, Redshift, S3 Tables 등 다양한 데이터 소스에 직접 접근하여 SQL이나 Python, Spark 작업을 수행할 수 있습니다 [4, 5].
*   **서버리스 노트북:** 인프라 프로비저닝 없이 몇 초 만에 확장되는 서버리스 노트북 환경을 제공하여, 초기 설정 시간을 획기적으로 단축합니다 [5].

### Data Agents (자연어 기반 분석)
Unified Studio에는 사용자의 자연어 지시를 이해하는 **Data Agents**가 내장되어 있습니다 [5].
*   **작동 방식:** "이 데이터에서 이탈률(Churn)을 분석해 줘"라고 입력하면, 에이전트가 이를 단계별 계획으로 분해하고, 실행 가능한 SQL이나 Python 코드를 생성합니다.
*   **생산성:** 복잡한 분석 로직을 직접 짜지 않아도 에이전트가 초안을 작성해 주므로 분석 속도가 빨라집니다 [5].

## 3. 머신러닝 인프라의 혁신 (SageMaker Updates)

생성형 AI 모델 개발 및 훈련을 위한 **Amazon SageMaker**의 기능도 대폭 강화되었습니다.

### SageMaker HyperPod 업데이트
대규모 분산 훈련을 위한 클러스터 관리 서비스인 HyperPod의 사용성이 개선되었습니다 [6, 7].
*   **복원력 강화:** 하드웨어 장애 발생 시 자동으로 복구하는 기능이 강화되어 학습 중단 시간을 최소화합니다 [8].
*   **Interactive Notebooks:** 기존에는 로컬에서 코드를 짠 뒤 클러스터로 옮겨야 했지만, 이제 HyperPod 클러스터 내부에서 직접 노트북을 실행하여 개발과 디버깅을 수행할 수 있습니다. 이는 대규모 모델 개발의 반복 주기를 단축시킵니다 [6].

### SageMaker AI Serverless MLflow
ML 실험 추적 도구인 MLflow를 이제 **완전 관리형 서버리스**로 제공합니다 [9].
*   **관리 부담 제거:** 사용자가 직접 트래킹 서버를 구축하고 관리할 필요가 없습니다.
*   **GenAI 추적:** 생성형 AI 애플리케이션의 입력, 출력, 메타데이터를 추적하여 디버깅과 성능 최적화를 돕습니다 [9].

### 실시간 추론 (Inference) 개선
**양방향 스트리밍(Bidirectional Streaming)** 지원이 추가되었습니다. HTTP/2 및 WebSocket을 통해 음성 인식(Speech-to-Text)이나 실시간 대화형 AI 서비스에서 지연 시간을 최소화하고 자연스러운 사용자 경험을 제공할 수 있습니다 [9].

## 4. 모더나이제이션 가속화: Spark Upgrade Agent

레거시 워크로드 현대화를 위한 도구로 **EMR Spark Upgrade Agent**가 소개되었습니다 [10].
*   **문제 해결:** Spark 버전 업그레이드는 호환성 문제로 인해 많은 시간과 노력이 드는 작업입니다.
*   **자동화:** 이 에이전트는 기존 애플리케이션을 분석하고, 업그레이드 계획을 수립하며, 코드 수정 및 검증까지의 과정을 자동화하여 엔지니어의 부담을 덜어줍니다 [10].

## 결론
이번 re:Invent의 데이터 및 ML 업데이트는 **'통합(Integration)'**과 **'지능화(Intelligence)'**로 요약됩니다. S3 Tables와 Unified Studio는 데이터의 사일로를 허물고 접근성을 높였으며, SageMaker의 새로운 기능들은 모델 개발에서 배포까지의 파이프라인을 더욱 견고하게 만들었습니다. 스마일게이트의 데이터 플랫폼과 게임 분석 워크로드에 이러한 도구들을 도입한다면, 데이터 기반의 의사결정과 AI 서비스 개발 속도를 한층 더 높일 수 있을 것입니다.
